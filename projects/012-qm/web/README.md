# QM 研究页

本地静态中文研究页，源数据是 `content.mjs`，展示生成器是 `build.mjs`。输出到本目录及 `site/012-qm/`，同时生成子项目 README 与可在网页访问的研究副本。

```text
node projects/012-qm/web/build.mjs
```

内容按能力 → 原理 → 模块 → 场景 → Pi 对照 → 个人价值 → 来源组织。筛选能力、切换空间、流程和场景均只更新说明性内容，不调用上游程序或外部模型。

原版未部署，网页通过本仓库 GitHub Pages 发布。Pi 的对应研究保留在 `010-pi` 并相互链接。
