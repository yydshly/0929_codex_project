# 研究证据与图片

`capability-atlas.png` 为 2026-09-29 在本地浏览器中截取的能力图谱页面。网页与视觉布局为本项目原创，文字依据上游固定版本整理。它证明本地展示页面已经运行，不代表上游技能已完成运行测试。

`agent-skills-full-map.svg` 与 `agent-skills-full-map.png` 是新制作的单张全量图，尺寸为 4000 × 7074；`agent-skills-full-map-preview.png` 为缩小预览。图中 25 项能力全部展开，扩展方向与个人意义为分析建议。

`full-map-layout.json` 保存每个技能在图中的位置与内容底部边界，用于网页定位与排版检查。`full-map-card-check.png` 为渲染质量检查样本，不是完整交付图。
