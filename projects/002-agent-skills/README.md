## 能力摘要

这是一个把工程方法写成 AI 工作流的技能库。六类工作分别帮助明确需求和验收、拆分任务、完成实现、验证和排错、审查改进、交付维护；可产出规格、任务计划、代码与测试、问题报告、流水线和发布准备材料。

对你当前研究开源项目，最有用的是借鉴目标澄清、上下文和决策记录；制作网页或个人工具时，可以直接采用开发和验证流程；需要长期运行后，再补齐自动检查、观测和发布管理。其意义是把一次次临时对话沉淀为可继续、可检查、可复用的工作方法。

后续可扩展自己的规范和模板，连接浏览器、测试与 CI，并用真实任务评测效果。技能指令由模型执行，硬性质量门禁仍需工具落实。

## 研究结论

该项目定位为软件研发流程技能包。它将需求、计划、实现、验证、审查和发布方法组织成按需读取的 Markdown 工作流，由宿主 AI 工具执行。25 个技能包括 1 个路由元技能与 24 个业务技能；9 个命令是入口，4 个角色提供不同审查视角。

对你当前可确认的工作——研究 GitHub 项目并积累独立子项目——最有价值的是建立清楚的研究问题、上下文、证据和结论。若以后制作 Web 演示或产品，再逐步采用实现、测试和发布技能。这里的优先级是结合当前对话和仓库结构给出的建议，并不假设你的职业、技术水平或业务需求。

## 本地阅读与运行

网页可直接打开 `web/index.html`，或在仓库根目录运行 `python -m http.server 8029 --bind 127.0.0.1 --directory site`，访问 `http://127.0.0.1:8029/002-agent-skills/`。页面无需安装依赖，可搜索、筛选、比较和查看详情。

运行 `pwsh -File projects/002-agent-skills/web/build.ps1` 可从两份研究数据生成网页数据与能力文档，并同步静态页面至 `site/002-agent-skills/`。详见 [网页说明](web/README.md)。网页通过仓库 GitHub Pages 工作流发布；上游技能未安装或实测。
