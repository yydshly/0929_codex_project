# MengTo/Skills · 能力查询网页

面向已经理解技能使用方式、需要按需查询具体能力的读者。

## 内容

- 全部 146 项技能，按 11 个实际能力方向重新组织；保留七个上游目录分类。
- 每项提供具体职责、对应场景、预期产出、能力边界和固定版本原文。
- 对二维与三维落叶、不同敌人系统、设计审查与持续质量约束等相近能力补充区别。
- 支持中文和英文搜索、多词匹配、能力方向与上游分类交叉筛选、更多结果和详情查看。
- 查询条件保存在地址中，详情有独立地址片段；可直接刷新恢复。
- 包含与当前研究、后续展示和长期经验积累相关的价值说明。

能力索引页是研究查询工具。新增 `styles-lab.html` 按六个风格技能正文构造真实页面，提供独立布局、风格切换、方向筛选与能力索引跳转。没有安装技能或运行上游演示代码。

[打开六种风格实景](http://127.0.0.1:4174/004-mengto-skills/styles-lab.html) · [构造与验证](../STYLE_LAB.md)

## 本地浏览

本页面使用 HTML、CSS 和 JavaScript，无外部字体、网络素材或运行依赖。直接打开 `index.html` 可以浏览；使用本地服务便于获得完整的地址与刷新行为。

在仓库根目录运行：

```powershell
python -m http.server 4174 --bind 127.0.0.1 --directory site
```

打开 [本地能力索引](http://127.0.0.1:4174/004-mengto-skills/)。这是本机预览地址，不是公网地址。

## 更新

中文具体职责和分组在 `../scripts/build_web.py` 中维护，基础技能元数据来自 `../skills-catalog.json`。在仓库根目录执行：

```powershell
python projects/004-mengto-skills/scripts/build_web.py
```

这会重新生成 `catalog.js` 和 `../CAPABILITIES.md`，并将页面文件与上游许可证同步到 `site/004-mengto-skills/`。只更新本项目的发布目录，不修改其他子项目。

修改 HTML、样式或交互后也应重新执行同步，并刷新本地浏览器。
