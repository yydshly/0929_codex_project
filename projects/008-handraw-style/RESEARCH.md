# 研究记录：Handraw Style

## 研究问题

厘清这套库的能力边界、主要内容、可实现画面类型和使用场景；制作可浏览的详细展示，使读者能够理解“主题、风格、版式、颜色、模式、模型”怎样组合。

## 来源与版本

2026-09-29 读取上游固定提交 [`b5c302e7164f287230ed80bde2f69f35aac39914`](https://github.com/yang0/handraw-style/tree/b5c302e7164f287230ed80bde2f69f35aac39914) 的 `README.md`、`SKILL.md`、三份 JSON 元数据、三份图鉴、`MANIFEST.md`、版式提示词、提示词脚本和模型能力配置。`version.json` 为 `1.2.29`。同步脚本保存所用资源与清单，并逐个验证其 Git 对象哈希。没有端到端运行上游 Skill；九组实测由本站依据条目改写请求并调用内置生图工具完成。另实际运行上游 `prompt_style.py` 的四种输入和参考图解析脚本，保留原始输出。

## 工作机制

1. `styles_200_reorganized.md` 保存风格的编号、原参考名称、生图名称及核心特征。`STYLES.md` 将它们组织为可浏览的图片图鉴。
2. `LAYOUTS.md` 与版式元数据定义社媒卡、信息图、漫画分镜；版式编号控制构图和文字结构，与画风编号职责不同。
3. `COLORS.md` 定义 36 个可指定的主题色。
4. Skill 处理缺省推荐、模式、语言、参考图和输出结构。其默认工作是写提示词；明确请求生图时才进入实际生图步骤。
5. `model_capabilities.json` 记录已标定模型的风格激活方式，未知模型倾向增加参考图。`prompt_style.py` 是确定性的提示词草稿工具，画廊和校验脚本则服务于索引维护。

## 上游工具实测发现

`prompt_style.py` 可按风格、颜色和版式编号生成提示词；选择 `SC-001` 时自动进入图文模式。风格单独输出虽然有“中文提示词 / English prompt”两段，英文段仍保留中文主题与特征。`--auto` 对手冲咖啡信息图推荐 #029 与 C-30 + C-34，但理由引用了公交站牌和城市方块等不贴题的特征，说明命令行启发式结果仍需人工判断。`SC-021` 命令行结果保留五种构图玩法，未执行 Skill 文档要求的单义玩法解析；本站的双拼图在生成前手动选择了“微缩浮岛型”。`resolve_reference.py` 对 `gpt-image-2` 的 #268/#276 选择名称加特征、无参考图，对未知模型则要求补参考图。这是配置决策，不等于出图质量保证。原始命令行输出见 [`trials/prompts/`](trials/prompts/)，可视化说明见[运行证据页](../../site/008-handraw-style/workflow.html)。

## 本研究的展示方式

本站全量图鉴展示上游全部 440 张编号图片；总览页的六张风格卡、四张版式卡与六张色彩图均直接使用固定提交的原图。另有九张明确标为“本次实测”的生成图和一张合成源照片。互动拼装器能访问全部 280 个风格、124 个版式和 36 个颜色的元数据，使用风格可见特征及上游版式原文做确定性预览；不声称复刻 Skill 的智能推荐或模型能力判断。首页首屏为本站实际生成的水墨猫。

## 验证范围

- 已核对 280 风格、124 版式和 36 主题色的元数据及全部 440 张编号图片，另有九张代表性生成图与一张合成源照片。
- 已验证全量图鉴的搜索、分类、详情与总览页的拼装器，以及桌面和手机站点副本。
- 已观察三种画风、一次换色、信息图、四格漫画、社媒卡、照片重绘和双拼转译，发现参考内容渗入、额外文字和尺寸不服从；详见 [TRIALS.md](TRIALS.md)。上游 Skill 仍未端到端运行。

## 结论

本库最有价值的部分是把视觉创作中原本含糊的选择拆成可组合的编号系统，并提供可复制的提示词。它适合快速探索插画、社媒图文、信息图和漫画页面。若需要精确文案、统一角色或可复现的品牌视觉，还需结合成图检查与后期制作。
