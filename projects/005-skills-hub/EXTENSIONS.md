# Skills Hub · 扩展方向

以下为研究建议，不是已实现功能或官方路线图。

## 01 · 版本锁定与可复现安装

- 现有基础：已记录来源版本，具备更新和设备同步历史。
- 建议增加：增加项目锁定文件、固定提交安装策略、升级差异和受控回滚。
- 预期价值：让团队明确每个项目使用哪一套技能版本。
- 扩展入口：installer.rs · skill_store.rs

## 02 · 兼容性检查与效果评估

- 现有基础：已有目录适配、状态检查和 CLI doctor 入口。
- 建议增加：声明系统、软件和工具依赖；用固定任务评估触发、输出与失败率。
- 预期价值：把文件安装成功与任务执行成功分别衡量。
- 扩展入口：tool_adapters · CLI · 独立评估模块

## 03 · 团队发布与治理

- 现有基础：支持 Git 来源和跨设备内容同步。
- 建议增加：增加团队技能目录、发布审批、角色权限、签名与操作审计。
- 预期价值：从个人管理扩展到团队可控的内容分发。
- 扩展入口：内容发布服务 · 身份权限层

## 04 · 可复用的技能组合包

- 现有基础：已有标签、批量操作和项目目标。
- 建议增加：将一组技能及版本组成前端包、入职包或发布检查包。
- 预期价值：减少逐个挑选和配置，支持项目模板化初始化。
- 扩展入口：skill_store.rs · 安装流程

## 05 · 面向外部系统的自动化接口

- 现有基础：已有 CLI、JSON 输出和对话式管理。
- 建议增加：在既有命令能力上完善 CI 接入、稳定协议或 MCP 服务。
- 预期价值：让项目初始化与技能维护进入已有自动化流程。
- 扩展入口：cli/args.rs · cli/handlers.rs

## 06 · 基于真实使用的反馈

- 现有基础：管理信息可描述安装和同步状态。
- 建议增加：在用户授权下采集触发、耗时、失败及人工评价，按技能版本比较。
- 预期价值：帮助用户决定保留、改进或淘汰哪些技能。
- 扩展入口：宿主工具集成 · 评估数据模型
