# Skills Hub · 从理解到使用

## 一句话定位

Skills Hub 是一个管理 Skill 的桌面工具：接入外部技能，集中增删改查，再分发到选定的 AI 工具或项目。默认是本地统一管理处，也可以通过 Git 仓库跨设备同步。

![Skills Hub 能力汇总图](assets/capability-summary.svg)

## 三种不同的东西

| 对象 | 作用 |
| :--- | :--- |
| Skills Hub 应用 | 管理技能的文件、来源、配置和分发目标 |
| 附带的 manage-skills-hub | 教宿主 AI 调用 skillshub-cli，操作 Skills Hub |
| 外部业务 Skills | 从 Git 仓库、本地目录或已有工具中接入，提供写作、审查等具体任务方法 |

将多个技能放在一起并不会自动把它们串成工作流。实际任务由读取这些技能的 AI 工具执行。

## 增删改查的具体含义

- 增：安装或导入外部技能。
- 删：删除技能；停用是保留内容、移除工具侧同步的另一种操作。
- 改：调整标签、目标、范围和启用配置，也可从来源更新技能内容。不能将此理解为内置了完整的正文编辑器。
- 查：搜索、筛选，查看说明、来源、文件与状态。

## 如何开始

1. 从[官方发布页面](https://github.com/qufei1993/skills-hub/releases)选择桌面安装包，打开应用。
2. 从研究过的仓库中挑选一个具体 Skill，使用其 Git 地址或本地目录添加。多技能仓库需确认目标目录。
3. 选择一个 AI 工具、一个试验项目，设置标签与同步范围。
4. 到目标 AI 工具中确认发现技能，再完成一个小任务。分别检查安装是否成功和效果是否符合预期。
5. 在 My Skills 中维护标签、启停与更新；有需要时再扩展到其他工具或设备。

可选的对话管理：在 Settings → AI Management 中启用配套 CLI 和管理 Skill，按提示刷新终端环境；确认 manage-skills-hub 已分发给目标工具，再让 AI 帮助查看和整理技能。单独安装 CLI 不会自动安装官方管理 Skill。

本研究没有实际安装、执行以上步骤；用法依据固定提交的 [README](sources/README.md) 和 [CLI 定义](sources/src-tauri__src__cli__args.rs)。

## 对当前研究工作的意义

你的研究集解决“有什么能力、是否值得采用”；Skills Hub 承接“已选中的技能如何安装、分发和维护”；目标 AI 工具完成实际任务，效果再记回研究集。

建议先用“1 个技能 + 1 个工具 + 1 个试验项目 + 1 次任务”验证。确认有用后再扩展，不必把研究过的所有技能全部安装。

预期价值是少做重复配置、掌握实际启用的技能、积累经过验证的个人工作方法。尚处于浏览与研究阶段时，可以先不采用。
