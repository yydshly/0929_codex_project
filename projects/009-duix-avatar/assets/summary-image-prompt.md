# Duix Avatar 总览图生成说明

## 最终提示词

制作一张专业、清晰的中文技术研究信息图，横向 3:2，大尺寸高分辨率，尽可能 3840×2560。标题为「Duix Avatar · 一图读懂」。暖白背景、深墨绿标题、鼠尾草绿模块、少量陶土橙强调；延续研究网页的安静编辑设计。使用清晰中文无衬线字体、细线图标和规则网格。以中间横贯画面的输入—模型流程—输出为视觉核心，上方定位与能力，下方硬件依赖、效果、场景和个人意义。保证所有文字清晰，不使用伪文字，不画真实人物样片，不使用营销数据。箭头严格遵循流程，不交叉缠绕。

必须完整表达下列文案，可以重排但不得改变事实：

标题：Duix Avatar · 一图读懂
副标题：真人视频＋新文案或音频 → 本地生成数字人口播
定位标记：非实时视频合成｜默认本机 GPU｜文档与代码研究，模型未实测

一、核心能力
人物素材复用 · 参考声音克隆 · 文案转配音 · 音频驱动口型 · 任务排队与导出 · 本地接口集成

二、输入与技术原理（主流程）
输入 A：人物视频（含清晰人声）＋目标文案
素材准备：FFmpeg 转码与提取音频
语音识别：FunASR → 参考文字
语音生成：Fish Speech 相关服务；新文案＋参考声音＋参考文字 → 新 WAV 配音
视频合成：Duix 视频服务；人物视频＋目标音频 → 新口播视频
输入 B：人物视频＋已有目标音频；跳过本次文本转语音，直接进入视频合成
输出：新配音（文案路径）＋可导出的口播视频
关键理解：预训练模型提供生成能力，人物视频提供参考素材；创建人物记录不等于从头训练个人模型。
已知边界：视频模型的具体网络结构、参数量与训练方法尚未确认。

三、依赖的模型与服务
FunASR：识别参考人声
fish-speech-ziming：参考声音处理与语音生成
duix.avatar：音频驱动视频合成
正式客户端访问本机 127.0.0.1；官方云 API 属于另一方案。

四、硬件与软件环境
官方完整部署参考：NVIDIA GPU，推荐 RTX 4070；内存 32GB；镜像存储空闲 100GB 以上；Windows 素材盘另留 30GB 以上。
Windows 10＋WSL / Ubuntu 22.04；Docker＋GPU 容器环境＋显卡驱动。
桌面端：Electron＋Vue＋SQLite＋FFmpeg；源码开发另需 Node.js 与构建工具。
标准版 3 项服务｜Lite 仅视频 1 项｜50 系列配置 2 项
最低显存、生成速度和本机兼容性尚未实测。

五、可以达到的效果与边界
目标效果：复用同一人物形象，以新文案或配音生成对应口型的视频。
需验证：音色相似度、口型同步、画面稳定性、专业词发音、长段落自然度。
不直接提供：实时对话、自动写稿、任意换装、全身动作控制。

六、适用场景
开源项目导读｜产品功能介绍｜系列课程与培训｜已有配音转口播｜多语言讲解（逐语种验证）

七、对我的意义
现在：把研究文档与能力图变成短视频导读。
以后：为个人工具制作安装、功能和更新讲解，减少重复拍摄。
