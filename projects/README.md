## 新增与维护

- 目录使用 `三位编号-英文短名称`，按历史最大编号加一；现有编号不改动、不复用。
- 新增时同步更新总索引、图览与本目录，保持数字升序，每个项目只保留一个入口。
- 研究过程和补充结论写入子项目，导航页不追加重复的“新增研究”记录。
- 具体规则见[收录规范](../docs/PROJECT_GUIDE.md)，部署方式见[部署说明](../docs/DEPLOYMENT.md)。
