# 001 · Awesome Agent Skills

**这是一个发现与筛选外部技能的开源目录。** 它集中整理不同作者的技能及技能集合，让你按目标任务找到方法：读写文档、设计页面、开发应用、处理数据、验证质量、制作媒体或串联工作流。选中的技能向 AI 助手提供步骤、规则、脚本与参考，由助手结合实际工具完成工作。

**可实现的结果是具体产物：报告、表格、演示稿、网页、业务接口、数据分析、测试证据、媒体素材或自动化流程。** 产物与效果取决于所选技能、可用工具、输入和验收；本研究未运行全库技能，不报告提效比例或收益保证。

## 我在什么场景下使用它

依据当前开源研究和网页展示工作，优先从以下任务开始：

| 你的具体任务 | 组合能力 | 预期得到的东西 | 完成时检查什么 |
| :--- | :--- | :--- | :--- |
| 发现新开源库，判断是否值得研究 | 搜索抓取 → 产品研究 → 文档整理 | 有来源的能力比较、适用场景、研究报告 | 结论是否有原始依据，能力与设想是否分清 |
| 把研究做成可分享的网页 | 视觉设计 → 前端实现 → 测试 → 部署 | 可访问、可交互的演示网站 | 手机布局、链接、关键操作和上线网址 |
| 准备报告、演示或项目视频 | 文档表格 → 视觉媒体 → 内容表达 | 可编辑报告、演示稿、配图、视频 | 引用、数字、版面和实际导出文件 |
| 原型开始面向真实用户 | 后端数据 → 身份通知 → 测试安全 → 诊断 | 业务接口、数据方案、测试与运行问题线索 | 真实数据、权限、关键路径和故障证据 |
| 同类研究和发布反复出现 | 知识整理 → 自动化 → 自定义技能 → 评估 | 研究模板、个人技能包、可重复工作流 | 来源、运行记录、典型任务的结果质量 |

后续价值来自积累：先试用少量技能，接入自己的资料与模板，再把验证过的步骤组合成流程。金融、医疗、科学、教育等专业方向按具体选题采用，不预设为当前工作重点。

## 摘要图、完整图与交互网页的区别

- **摘要图**：20 类能力的静态 SVG，适合直接嵌入 README，帮助快速理解。
- **完整图**：同一张 SVG 中放入全部 1,108 个目录条目，适合放大查阅。
- **交互网页**：为完整图增加搜索、拖动、缩放和右侧详情；这些交互需要独立网页运行。
- **首页摘要**：以响应式卡片直接展开内容，中文能力、产物和使用时机不依赖点击。

## 构建与部署

本项目为无需外部依赖的静态站点。执行 `node projects/001-awesome-agent-skills/web/build.mjs` 构建，再运行 `node projects/001-awesome-agent-skills/web/verify.mjs` 检查。

源码位于 `web/`，发布文件位于总仓库 `site/001-awesome-agent-skills/`。GitHub Actions 构建、检查并将 `site/` 发布到 GitHub Pages。详情见 [Web 说明](web/README.md)和[部署记录](../../docs/DEPLOYMENT.md)。
