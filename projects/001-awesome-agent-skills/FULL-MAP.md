# 全量能力地图

本图覆盖研究快照中的 **1,108 个目录条目**，归纳为 **20 个主方向**。每个条目在同一张 SVG 中出现一次，展示上游能力简介的中文翻译并保留原始链接。

- [打开交互网页](web/dist/atlas.html)：查看全图、按方向定位、搜索具体技能、放大和平移。
- [打开完整 SVG 图](web/dist/atlas.svg)：单个矢量图文件，可以保存、放大、分享；无需网页脚本。
- [结构化全量数据](atlas-catalog.json)：条目、来源、分组依据、图中位置和方向分析。

## 图中包含什么

| 层次 | 内容 | 证据口径 |
| :--- | :--- | :--- |
| 全图顶部 | 从发现、制作、连接、验证、交付到复用的工作链 | 依据当前开源研究与网页展示工作归纳 |
| 每个方向 | 能力范围、使用场景、目的效果、可扩展方向、对你的意义 | 方向层面的研究分析 |
| 每个技能方块 | 技能名称、中文能力简介、原始来源链接 | 固定版本 README 上游原文的中文翻译 |
| 网页详情 | 中文简介、可展开的英文原文、所属方向的场景和价值 | 明确标注为方向归纳；40 项另有中文具体解读 |

全图顶部和每个方向的五维说明均包含在下载的 SVG 内，不依赖网页侧栏。超过 48 项的方向拆为若干分区，每个分区重复方向说明，方便局部阅读。所有分区仍在同一张图中。

## 全量的定义

来源为 [VoltAgent/awesome-agent-skills 固定版本 ed106e8](https://github.com/VoltAgent/awesome-agent-skills/blob/ed106e8edc7c6d04fe3aedcbfaed1b43247f56a7/README.md)，快照日期 2026-09-29。目录共解析 1,113 个命名列表链接，排除 5 项明确标注为非技能的配套工具，得到 1,108 项，来自 78 个上游分组。

**目录条目不等于独立技能数量。** 部分入口指向技能集合或注册目录；集合内部未递归展开。这里的 100% 指该快照中纳入统计的目录条目全部入图，不代表验证了外链中的所有技能文件，也不代表当前上游版本永久不变。

## 分类与分析方法

20 个方向是便于理解的研究分类，与旧版 40 项代表技能图鉴的 9 类导航以及能力矩阵的 11 类代表能力不同。每个条目只选一个主方向，避免重复计数；跨领域能力以原始简介为准。

分类首先采用研究者依据目录简介做出的明确归类，其余按名称、简介关键词和上游分组归类。数据中保存每条的 `basis`，便于复核。分类规则和方向分析集中在 `web/atlas-model.mjs`，后续可以调整而不改动原始简介。

为避免没有依据的逐项功能承诺，没有把 20 个方向的通用价值写成 1,108 项技能均已具备的功能。网页详情将方向归纳和已有的 40 项具体中文解读分别标明。全部 1,108 项能力简介现已逐项译为中文，英文原文收在详情的对照区；技能名称、产品名及必要技术缩写保留。未安装或执行这些技能。

中文译文位于 `web/translations-zh.tsv`，按固定快照的条目标识对应。`web/localize.mjs` 检查译文是否完整、是否有重复及源快照是否改变，防止更新来源后沿用错位译文。上游已截断的简介明确标注截断，不补写未知内容。翻译上游效果宣称不代表本研究验证了该效果。

## 对当前研究工作的意义

优先关注搜索与抓取、文档交付、视觉设计、前端工程、测试验证：这些方向与当前“发现项目 → 理解能力 → 做出网页 → 验证展示”的工作直接相连。

当需要从演示走向真实应用时，继续看数据、后端、身份和云平台；当同类研究频繁重复时，再结合自动化和 Agent 方法沉淀个人流程。金融及行业专业方向作为按需选项，不预设你的职业或商业目标。

## 后续扩展

1. 对选中的外链集合递归建二级目录，建立“目录入口 → 单项技能”关系，分开统计两种数量。
2. 为每项技能补充中文解读、输入条件、具体产物和验收指标，记录逐项来源，逐步替换方向层面的通用分析。
3. 引入多标签与交叉关系，展示组合工作流，同时保留唯一条目计数。
4. 对实际采用的技能保存运行样例、结果检查和成本记录，区分能力声明与实测效果。
5. 对上游版本做新增、移除和能力变更对照，形成可更新的个人能力地图。
