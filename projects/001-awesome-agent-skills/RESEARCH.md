## 项目定位

贡献说明明确：该仓库整理独立技能仓库的链接。研究对象因此分为目录的发现机制和外链技能的组成。VoltAgent 框架、该目录与某个技能包具有不同职责。[贡献说明](https://github.com/VoltAgent/awesome-agent-skills/blob/main/CONTRIBUTING.md)

上游声明收录技能经过筛选，但没有逐项审计。本项目将“被收录”视为候选资格，不视为正确性认证。[目录说明](https://github.com/VoltAgent/awesome-agent-skills/blob/ed106e8edc7c6d04fe3aedcbfaed1b43247f56a7/README.md)

## 底层机制

技能是以 `SKILL.md` 为入口的文件包，可包含脚本、参考资料和模板。名称与描述用于发现，正文在激活时加载，辅助资源按需读取。机制发生在推理时的上下文与工具执行层，不要求修改模型参数。[格式规范](https://agentskills.io/specification)

典型路径为：发现技能 → 解析元信息 → 向模型提供目录 → 模型或用户选择 → 加载正文 → 使用工具执行。宿主可以通过文件、接口或上下文注入提供内容，具体加载与权限支持因产品而异。[实现指南](https://agentskills.io/client-implementation/adding-skills-support)

本项目按以下职责分析方案：

| 组成 | 负责什么 | 不应推断什么 |
| :--- | :--- | :--- |
| 技能目录 | 候选入口与分类 | 自动安装和质量保证 |
| 技能包 | 方法、规则、资源与步骤 | 自动取得账号或权限 |
| 模型 | 理解、判断、生成 | 每次输出必然正确 |
| 宿主 Agent | 上下文、工具调用与权限 | 所有平台支持完全相同 |
| 工具或服务 | 计算、读写、外部操作 | 返回成功就满足业务目标 |
| 验收流程 | 对照输入和目标检查产物 | 用 Agent 自评替代检查 |

## 三个代表样本

**网页测试：流程＋工具。** `webapp-testing` 包含应用类型判断、服务启动辅助脚本和页面检查步骤。它将操作顺序与工具用法打包；实际使用仍需应用、测试数据和明确断言。页面能打开不能证明关键业务路径正常。[技能文件](https://github.com/anthropics/skills/blob/main/skills/webapp-testing/SKILL.md)

**表格交付：产物＋检查。** `xlsx` 围绕表格文件、公式、重算和错误检查提供流程。其说明区分公式能计算与公式逻辑正确；业务总额核对仍须另设。运行时假设及许可证需要按目标环境核对。[技能文件](https://github.com/anthropics/skills/blob/main/skills/xlsx/SKILL.md)

**数据库：规则＋参考。** 实际技能名是 `supabase-postgres-best-practices`，包含规则分类与参考文件。目录展示名和实际目录名可能不同，不能据展示名直接拼安装路径。优化效果应在一致数据与负载下验证，不应将规则说明当成已测收益。[技能文件](https://github.com/supabase/agent-skills/blob/main/skills/supabase-postgres-best-practices/SKILL.md)

样本展示了过程控制、产物规范和领域规则三类价值；不能据此统计推断全库成熟度。
